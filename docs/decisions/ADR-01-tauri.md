# ADR-01 · Tauri 2 como contenedor

- **Estado:** Aceptada.
- **Registrada:** 2026-10-02 (cuando entró en el informe técnico)
- **Ámbito:** Transversal

## Decisión

Tauri 2 como contenedor

## Alternativas descartadas

Electron, Flutter, Godot/Unity, nativo por plataforma

## Motivo

Binario ~10 MB, Rust para sync/OAuth, ecosistema web para animaciones

## Consecuencias

Probar en dos motores web (WebKit en macOS, Chromium en Windows)
