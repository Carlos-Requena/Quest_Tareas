# ADR-06 · Motion para transiciones y GSAP para secuencias

- **Estado:** Aceptada.
- **Registrada:** 2026-10-02 (cuando entró en el informe técnico)
- **Ámbito:** Transversal

## Decisión

Motion + GSAP

## Alternativas descartadas

Solo CSS, solo Motion, PixiJS

## Motivo

Motion para layout y transiciones; GSAP para secuencias largas encadenadas

## Consecuencias

Dos librerías que conocer; regla: GSAP solo en secuencias
